# Healthcare Insurance Cost Analysis

## Overview
Analyzed a dataset of 1,338 insured individuals to identify what factors most influence medical insurance charges.

## Key Finding
Smoking status has a dramatic effect on cost — smokers pay an average of $32,050 in charges, compared to $8,434 for non-smokers, nearly a 4x difference.

## Methodology
- Explored and summarized data using Excel pivot tables
- Verified the finding using SQL (SQLite) queries
- Visualized the result using Python (pandas + matplotlib)

## Files in this Repository
- `insurance.csv` — raw dataset
- `project_graph_smoker_health_insurance_.png` — chart showing the cost difference
- SQL query screenshot — shows the import and verification in SQLite

## Tools Used
Excel, SQL (SQLite), Python (pandas, matplotlib)

## Conclusion
This finding supports why insurers price premiums based on smoking status — the cost difference in this data is large enough to be treated as a primary risk factor.
